Pour ajouter Dismoi à votre navigateur Edge, vous devez y **autoriser les extensions Chrome**.
Cela prend **2 minutes, voici comment procéder :**

**1.** Vérifiez [ici que vous avez bien la nouvelle version de Edge](https://support.microsoft.com/fr-fr/help/4501095/download-the-new-microsoft-edge-based-on-chromium) basée sur Chromium.

**2.** Dans le menu de votre navigateur Edge en haut à droite, cliquez sur **Extensions**.

![extensions menu navigateur Edge](/img/content/extensions-edge-menu-navigateur.png)

**3.** Tout en bas de la fenêtre, à gauche, activez ensuite l’option « **Autoriser l’installation d’extensions d’autres magasins**« 

![Edge Activer extensions externes pour Chromestore](/img/content/Edge-activer-extensions-externes-pour-chrome.png)

**4.** Enfin [suivez ce lien vers Chrome Web Store pour ajouter Dismoi à votre navigateur](https://chrome.google.com/webstore/detail/dismoi/fpjlnlnbacohacebkadbbjebbipcknbg?hl=fr)

![Dis Moi Chrome store](/img/content/Dis-moi-chromestore-2.png)

**Si vous rencontrez un problème** durant l’installation, [contactez nous ici](/fr/contact), surtout n’hésitez pas !
