## Désolé, Dismoi n’est pas disponible sur votre navigateur

Actuellement, l’extension Dismoi existe **uniquement sur ordinateur pour les navigateurs [Firefox](https://addons.mozilla.org/fr/firefox/addon/lmem/), [Chrome](https://chrome.google.com/webstore/detail/dismoi/fpjlnlnbacohacebkadbbjebbipcknbg?hl=fr), [Microsoft Edge](/fr/edge) et [Opera](/fr/opera)**.

Elle n’est donc pas disponible :

-   ni sur smartphone et tablette
-   ni sur les autres navigateurs d’ordinateur : Safari, Edge, Internet Explorer, etc.

Merci pour votre compréhension, à bientôt.
