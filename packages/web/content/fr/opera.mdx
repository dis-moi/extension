## ![logo-opera](/img/content/logo-Opera-navigateur-chrome.png)Les internautes sous Opera peuvent utiliser des extensions Chrome comme Dismoi.
Cela prend 2 minutes, voici comment procéder :

1.  Installer [Download Chrome Extension](https://addons.opera.com/fr/extensions/details/install-chrome-extensions/) à partir du store Opera
2.  Télécharger [Dismoi sur le Chrome Web Store](https://chrome.google.com/webstore/detail/dismoi/fpjlnlnbacohacebkadbbjebbipcknbg?hl=fr)
3.  Si l’extension n’est pas activée, aller dans la liste de vos extensions et passer l’extension Dismoi en actif.
