## 1. Sur PC : Extension navigateur DisMoi

Aujourd’hui, l’extension navigateur DisMoi est disponible sur ordinateur et est compatible avec les navigateurs [Chrome](https://chrome.google.com/webstore/detail/dismoi/fpjlnlnbacohacebkadbbjebbipcknbg?hl=fr), [Firefox](https://addons.mozilla.org/fr/firefox/addon/dismoi/), Opéra et [Edge](/fr/edge).

À l’instar des autres extensions navigateurs (Adblock, LastPass, Grammarly, Honey..), pour le moment l’outil web DisMoi n’est pas disponible sur les navigateurs Safari.

**Si vous rencontrez un problème** durant l’installation, consultez notre [rubrique d’aide](/fr/aide) ou [contactez-nous ici](/fr/contact).

![Amazon Antidote](/img/content/dismoi-screenshot-amazon-antidote-mounted-website-desktop-1000px.jpg)

## 2. Application mobile DisMoi sur Androïd

L’application DisMoi sous Androïd sera bientôt disponible en téléchargement sur Google Play. Dans un premiers temps, elle pourra interagir avec le navigateur Chrome de votre système d’exploitation mobile Android.

Ainsi Dimoi sera disponible sur les mobiles Samsung, Google, Huawei, Sony, Xiaomi, ou encore OnePlus.

![DisMoi sur Android](/img/content/capture-mobile.jpg)

## 3. Application mobile Dis Moi sur iOS / Apple

DisMoi sera bientôt disponible sur votre Iphone en téléchargement au sein de l’Apple Store. L’application Dis moi prendra la forme d’une application avec navigateur intégré, compatible pour le système d’exploitation mobile iOS d’Apple.

Ainsi DisMoi sera disponible sur les mobiles Samsung, Google, Huawei, Sony, Xiaomi, ou encore OnePlus.

PS : “DisMoi” s’écrit tout attaché, mais comme beaucoup de nos utilisateurs l’écrivent en détaché (“Dis Moi”), parfois même sans le S (“DiMoi”) nous avons pris la liberté de l’écrire de plusieurs façon sur cette page (“Dis Moi” “DiMoi”), ceci afin d’être certain d’être retrouvé.

_Si vous souhaitez être informé(e) de la l’arrivée prochaine de DisMoi sur mobile Androïd ou de la sortie de l’application DisMoi sur I-Phone (iOS/Apple), n’hésitez pas à [nous contacter](/fr/contact)._
