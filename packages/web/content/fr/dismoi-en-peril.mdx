Le service DisMoi risque de prendre fin ces prochaines semaines.

Le code actuel n’est en effet pas adapté aux nouvelles exigences des navigateurs Chrome et Firefox. Comme indiqué dans [ce communiqué](https://developer.chrome.com/blog/resuming-the-transition-to-mv3?hl=fr), à tout moment, Chrome peut désormais désactiver l’extension.  Ce sera ensuite le tour de Firefox, qui suit les évolutions de Chrome.

[Johan](https://github.com/lutangar/lutangar) et [Jalil](https://github.com/JalilArfaoui) ont listé les évolutions du code nécessaires (lien). Si vous souhaitez aider à adapter le code de l’extension à l’[API V3](https://developer.chrome.com/docs/extensions/reference/api?hl=fr), il est open source et [accessible ici](https://github.com/dis-moi/extension)

Nous avons également prévu un nouveau design de l’extension pour améliorer l’expérience de notification (la notification doit être visible, mais ne pas déranger pour autant). Si vous voulez en savoir plus ou contribuer à ce design et son intégration, vous pouvez contacter [Maarten](https://github.com/MaartenLMEM)
Et pour toute autre question ou remarque, n’hésitez pas à le solliciter aussi.
