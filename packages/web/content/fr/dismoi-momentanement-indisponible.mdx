## Désolé, sur Firefox le service est momentanément indisponible

!L’extension navigateur DisMoi est **en attente d’une vérification** sous Firefox.

_La raison est un peu technique : l’équipe de modération Mozilla ne pouvait pas entièrement regénérer le code à partir du paquet qu’on leur a livré. Malgré le fait que notre code soit open source et entièrement disponible, ils ont choisi de dépublier les dernières versions._ 

On préfère donc vous dire de **revenir plus tard** que de vous envoyer sur **une version ancienne qui ne marche pas bien**.

!Néanmoins, sachez que **si vous installez [cette ancienne version](https://addons.mozilla.org/fr/firefox/addon/dismoi/)** (qui ne marche pas donc bien encore), elle sera **mise à jour automatiquement** lorsque l’équipe Firefox aura validé la dernière version, sans doute ces prochains jours.

Si vous êtes sur Twitter, nous pouvez [nous suivre ici.](https://twitter.com/DisMoiCompagnon)

Vous pouvez aussi installer DisMoi [sur Chrome](https://chrome.google.com/webstore/detail/dismoi/fpjlnlnbacohacebkadbbjebbipcknbg) en attendant.

Dans cette attente, **veuillez bien nous  excuser de la gêne occasionnée.**
