### Sous Firefox

**1ère méthode :** Cliquez droit sur l’extension Dismoi puis cliquer sur désinstaller.![bulles-firefox-suppression](/img/content/image-supprimer-bulles.png)

**2ème méthode :** Dans le menu Menu Firefox ![Menu Firefox](/img/content/menu-firefox.png)en haut à droite de votre navigateur, cliquez sur « Modules ». Puis, en face du nom « Dismoi » cliquez sur « Supprimer ».

Si vous souhaitez réinstaller Dismoi ensuite, rendez-vous sur la page [Dismoi de firefox add-ons](https://addons.mozilla.org/fr/firefox/addon/bulles-fr "Bulles Firefox extension")

### Sous Chrome

1\. Pour désinstaller l’extension Dismoi dans votre navigateur Chrome, il vous suffit de faire un clic droit sur l’icone de l’extension en haut à droite de votre navigateur.
2\. Vous pouvez ensuite choisir l’option _Supprimer de Chrome_ pour désinstaller complètement l’extension de votre navigateur.
